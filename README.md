# tgshd — Telegram Shell Daemon

A small Go daemon for Ubuntu servers that processes commands sent over Telegram
and runs periodic checks — providing basic tools for server manipulation and
monitoring (ping, speedtest, power/UPS via NUT, ZTE modem SMS, and custom
scripts).
